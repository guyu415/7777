# 任务 3 · 沙海初愿

## 本轮范围

在原静态工程内增量添加探索章。画面仍为占位。任务 3 最初使用机制短文本；任务 4 已替换为《愿骨2.txt》约束下的序章与巡视文本，仍未展开远期剧情。新章数据在 `dist/exploration.js`，由原 `story.js` 合并导出；原两地演示及状态系统仍保留给旧周目。

## 探索规则

- 完成上庭序章教学后：首日午时 12:00，6 行动点，五个地图地点全部解锁。新游戏教学阶段有 `prologue-active` 标记，地图行动与沙暴事件均暂不生效；任务 3 旧档无此标记，可直接继续。
- 每次移动到不同地点：1 行动点、30 分钟。返回去过的地点也收费；当前地点按钮禁用，打开地图/查看状态不收费。
- 每个地点一次深入调查：1 行动点、30 分钟，获得对应线索。调查不可重复，地图按钮和对话选项共享标记与结算。
- 抵达事件分午时 `[11:00,13:00)` 与未时 `[13:00,15:00)`。同地同一时段事件只触发一次；重访另一时段会触发另一事件。
- 集市每个时段在 3:1 的候选中抽取一个；种子与结果随存档保存。
- “等到申时”不消耗行动，将时间推进到首日 15:00；用于主动汇合或行动不足时继续。
- 申时沙暴优先于抵达旁白、选项或随机事件；开始后普通探索暂停。

## 边界与主线

15:00 精确到点强制触发。若一次移动恰在 15:00 完成，使用**到达地点**与已获得线索筛选入口。若从调试等方式进入非整刻，长动作中途跨过 15:00、还未完成移动，则使用**原地点**。动作只结算一次；强制改道不另扣行动。

调查选择确认时记录线索，随后推进该行动的时间；恰在 15:00 完成的调查可以让入口使用刚发现的线索。风暴改道时余下行程取消，读完入口后统一进入 `sahaiConverge`：半埋驿站相遇 → 简短选择 → 铃兰愿望 → 预览结束。地点、相关物品和风暴互斥锁始终保存，不能通过读档或刷新重复触发已完成入口。

## 存档

新章沿用 schema v2，使用章节标记区分。旧 v1/v2 档继续原来的演示；新游戏生成六点探索周目。不会把旧档擅自变成新周目，也不会清除手动档位。新章的五地访问、时段标记、调查标记、物品、随机状态、沙暴入口和中途对话均可存读。

常驻查看可重复，收取只计一次：2 / 2 / 3 / 2 / 1。小物拾取、询问、核对和倾听不增加行动开销；深入调查仍扣 1 点并推进 30 分钟。拾取、交谈、时辰内容各有一次标记。物品归还与保留互斥，分别影响入世或越界；线索核对影响循序，原察觉阈值继续生效。时间窗口左闭右开；驿站过路人离开后不再重新出现。申时后关闭外围探索，强制主线仍优先。

未表达的愿力只有来源与性质，收取后卡片愿文仍留空。物品引出的交谈与两处明确祈愿，须实际显示全文后才生成可读愿文。归庭叶片采用本轮实际收取总量，不固定为教学的 12，也不因归档重复加算。
