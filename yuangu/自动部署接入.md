## Cloudflare 关联步骤

在 Cloudflare Workers & Pages 打开现有 odd-disk-c531，进入 Settings → Builds → Connect，关联 guyu415/7777。

| 设置 | 值 |
|---|---|
| Production branch | yuangu |
| Root directory | yuangu |
| Build command | npm test |
| Deploy command | npx --yes wrangler@4 deploy |

Worker 名称必须保持 odd-disk-c531，wrangler.json 会发布 dist/ 静态文件并保留 game.xiaoman.xyz 自定义域名。无需把 Cloudflare Token 或 GitHub Token 写入源码。测试需要 Node.js，建议 22 或更高版本。

## Claude 修改流程

1. 在分支 yuangu 上读取 yuangu/CLAUDE.md、游戏入口和本次相关模块。保留其他未提交修改。
2. 用户要求改游戏时，直接修改 yuangu/ 下的代码或剧情数据，不只给替换文案。
3. 有 Node.js 时在 yuangu/ 运行 npm test；没有运行环境时明确报告未运行。
4. 用户要求上线时，把游戏变更提交至 yuangu 分支。发布分支无需合并到 main。
5. 仅在 Cloudflare Builds 已关联该分支后，推送才会触发网站自动更新。检查此次部署成功，并验证线上实际变更后再报告上线。
