## 使用

1. 把整个压缩包解压进 Kelivo 已绑定的工作区，保留目录结构。
2. 项目根目录为 yuan_gu_game_v19，网页根目录为它里面的 dist。
3. dist/index.html 是游戏入口。这个项目没有打包步骤，HTML/CSS/JS 都可直接编辑。
4. 本地预览需 HTTP 静态服务，不能仅用文件预览器打开 HTML。有 Python 时在项目根目录运行：

```sh
python3 -m http.server 8080 --directory dist
```

如果 Kelivo 当前运行环境不支持网页预览，应明确说已改了哪些实际文件、导出哪个可运行目录，不能把文件预览或一段文字回复称作已运行游戏。
