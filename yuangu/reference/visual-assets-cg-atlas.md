# 愿骨 · 收取愿力、沙海绘卷与关键 CG

本批用内置图像生成工具绘制；粒子运动用独立 Canvas 实现。原 UI 图片、剧情、数值、存档格式不变。

## 成品与提示词规格

| 工程路径 | 实际绘制规格与提示词要点 |
| --- | --- |
| `dist/assets/cg/sahai-atlas.png` | 横向16:9古风沙海王城鸟瞰绘卷，战场遗址、王城井边、临时集市、城外马场、半埋驿站五处独立地景，沙路自然连接；旧金、赭黄、褪朱红、绢帛边缘；无字、无按钮、无卡片。参考既有战场背景。 |

CG 实际由 `cinematic-art.js` 依据已有剧情节点选择，不将未到达的图插入剧情；地图点击沿用原移动消耗、地点锁定和强制主线。特效只在点击收取后出现真实愿力增量时播放，读档、回顾和面板渲染不触发奖励。隐藏界面、打开面板、离开节点、切后台或调整尺寸会清理瞬态特效；系统减少动态效果设置下不播放粒子。

铃兰双人 CG 初稿曾出现掌心泥土，已重绘成直接从掌心生长的版本；旧初稿未加入发布素材。
