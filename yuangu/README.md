# 愿骨 · 静态 Galgame 序章预览

针对 iPhone 横屏（包含安全区、动态视口）制作，竖屏提供兼容布局。无依赖、无聊天模型、无 API、无后端、无外部字体或图片请求。所有游戏状态存于同源浏览器 localStorage。

## 运行

用任意静态服务器把 `dist/` 作为网站根目录，例如 `python3 -m http.server 8080 --directory dist`，然后访问 http://localhost:8080。ES 模块需要 HTTP 服务，请不要直接双击 file:// 文件。

## 文件分工

- `dist/story.js`：唯一剧情入口。开场、人物显示名、场景、地图、对话节点、分支、演示数值。
- `dist/events.js`：状态条件、一次事件、互斥组、随机池、物品前置、时窗与固定主线规则。
- `dist/court.js`：可点击的上庭开幕、领命规则、落凡与归庭闭环。
- `dist/tree-data.js`：愿力树的愿文、来源、性质、节点解锁与初叶数据。
- `dist/wish-tree.js` / `dist/tree-panel.js`：五类愿力树记录的状态投影与独立界面。
- `dist/prologue.js`：保留的线性序章、战场首次收取、选项与地图教学。
- `dist/exploration.js`：沙海初愿的五个地点、时段事件、调查线索、移动消耗与十条沙暴入口。
- `dist/engine-core.js`：通用状态机、行动结算、存档校验与存储。
- `dist/app.js`：逐字动画、界面和按钮事件。
- `dist/debug-panel.js`：制作面板，仅 `?debug=1` 显式开启。
- `dist/style.css`：横屏/竖屏布局、占位背景与占位立绘。
- `reference/愿骨2.txt`：本轮正式序章的唯一设定源；`reference/愿骨.txt` 留作旧版记录。两者均不随静态页面公开提供。
- `tests/core.test.js`：剧情图、主支线、地图、资源、存档、坏数据的检查。

只修改既有场景中的对话、选项、跳转与消耗时，无须改程序。每个节点声明 `scene`、`speaker`、`actor`（可为 null）、`text`，并指定 `next`、`choices`、`end: true` 或插入事件用的 `resume: true`。选项用 `target` 跳转，可配置 `cost: { ap, minutes }` 与唯一 `once` 标记。`minutes` 表示推进分钟，`ap` 表示行动消耗；愿力为已收取总量，不作为动作货币。新增人物显示信息可放入 `characters`，新增场景与地图位置可放入 `scenes` / `map`；新增美术样式另行修改 CSS/资产。

当前从上庭临行写起，依次经历初次下凡、金铃与愿力认知、首次收取、外围巡视、风沙中的无谌相遇，止于他亲口表达铃兰之愿。没有展开远期剧情或出生秘密。数值与时程为游戏机制，不属于原设定；新周目愿力从 0 开始，教学收取一次增加 12。

## 操作与进度

点击对话框先补全逐字内容，再点击推进。新游戏在愿力树下苏醒，依次操作愿力树、金铃、容衡与落凡台，进入保留的战场剧情；完成首次收取和地图教学后，在午时 12:00、6 行动点进入“沙海初愿”。教学不消耗行动，地图五处地点随后可自由往返，每次移动或深入调查消耗 1 行动点、推进 30 分钟。首日申时 15:00 触发沙尘暴，各入口最终在半埋驿站汇合。回看可查看本周目已读文本。旧周目载入后仍沿原来的两地演示继续，体验新地图请选择新游戏。

每次节点推进都会自动存档。另有三个手动存档，覆盖时确认；读档恢复全部状态与事件进度；本句逐字显示从头播放。标题页继续读取当前浏览器最近记录。新游戏覆盖自动存档并保留手动存档。v1 记录可迁移至 v2；其他不兼容或损坏记录不加载。浏览器禁止存储时会明确提示。

文字速度可在标准、快速、即时之间切换。Esc 关闭弹窗；对话框可用键盘聚焦并以空格/回车操作。系统减少动态效果时直接显示全文。

## 历史增量：状态系统

保留原项目、页面、站点地址和存档命名空间。公开显示时辰、剩余行动点、已收取愿力；五个隐藏值仅在制作面板显示。“随身”入口显示物品与已读行迹，地图遵守地点解锁。

普通链接没有调试入口。制作时在 URL 后加 `?debug=1`，点击“制作调试”，可调整公开/隐藏值、日与时刻、物品数量和地点；查看事件状态、随机种子与完整标记；清空本游戏四个存档（保留文字速度）。它是客户端制作开关，不是访问控制；没有服务端或外部 API。

本轮规则为机制样例，不规定角色真实好感变化或原设定的时程。开场沙丘新增“稍候一刻”，用于验证首日 15:30 固定主线。剧情仍停在初次铃兰愿望。

## 历史增量：任务 3 · 沙海初愿

新章使用 `exploration.js` 的独立数据，沿用现有状态、事件、存档和调试程序；保留 `legacyStory` 与旧节点供已有周目继续。新章的固定主线为首日 15:00，前版 15:30 的规则仅对旧周目生效。

五个地点为战场遗址、王城井边、临时集市、城外马场、半埋驿站。午/未两个时段有不同抵达事件，集市保留权重随机样例。深入调查记录线索，且每个地点只能调查一次，不能反复刷取。地图和对话选项都可发起调查，消耗相同。

五地各有“有对应线索 / 无对应线索”两条沙暴入口，总计十条，最后接回同一主线。移动完成时刻恰好为 15:00 时按到达地点分支；若长行程中途遇到申时，则按尚未离开的当前地点分支。强制主线不额外收费。行动不足可“等到申时”，不消耗行动。

规则、测试矩阵见 `EXPLORATION.md`。任务 3 完成时自动检查为 38 项，包括原状态系统回归。

## 历史增量：任务 4 · 上庭序章

保留引擎、状态字段、地图费用、事件调度及存档格式，只增补序章数据、替换当前周目的测试叙事，并更新相应界面文案。`engine-core.js` 无修改。

新游戏先通过两种注意方向学习选项；金铃只震动不发声，苑感知愿力强弱与大致性质，直至凡人开口才得知具体愿望。容衡以简短纠正与命令划定日落前外围巡视、不擅改凡人命数的边界。首次收取是带物品前置与一次性标记的真实数值操作，之后开放地图；领命期间无法通过地图调查或等待跳过教学。

已有两地旧档及任务 3 探索档均可继续，不强插序章、不重复加愿力；体验完整开场请选择新游戏。新增 5 项序章行为检查，总计 43 项通过。浏览器核对收取前存读档、0→12 愿力、教学解锁、地图移动调查、沙暴汇合与结尾，667×375 横屏长文本完整可见。

## 当前增量：任务 5 · 上庭场景与愿力树

保留标题页、五地地图、行动消耗、状态引擎与既有剧情，在其前后接入可操作上庭开幕和归庭闭环。愿力树是与“随身”分开的独立入口，提供枝叶、微光、根系、年轮、归档五类记录。未被表达的具体愿文不显示；收取后也只记录已知内容，不赋予读心能力。

新流程请从“新游戏”进入；任务 3/4 存档仍可继续原进度并从沙海末尾归庭。当前 51 项自动检查通过，规则与文件分工见 `TREE_SYSTEM.md`。

## 矮屏横屏与主屏幕入口

`dist/short-landscape.css` 专门处理横屏且高度不超过 500px 的三段布局：52px 状态栏 / 自适应场景 / 不超过 34dvh 的对话框。长正文在自己的区域内滚动，场景不会被对话高度覆盖。正文 16px、底部功能按钮 40px；左右安全区通过 env 处理。桌面与竖屏继续使用原布局。

新增 `dist/manifest.webmanifest`（display: standalone）、Apple 主屏幕 meta 和独立 PNG 图标。Safari 添加到主屏幕后可从图标进入。未接入后端，也未添加离线缓存。游戏状态字段与存储键不变。三个要求尺寸及长文本、安全区检查记录见 `QA.md`。

### 预览 10：铃兰终幕与视觉小说功能

无谌亲口表达愿望后，苑在他掌心种下铃兰。一缕愿力未能归拢，容衡出现在门外，只说“过来”。四个末尾选择互斥，保存各自的标记与数值，读过对应短句后黑屏显示《愿骨》与“预览章结束”。结尾记录内仍可归庭整理愿力树；铃兰单独记为已回应、未完整收取，不计入战后归档总量。

- `finale.js`：终幕、四个选择、影响与数值说明；`chapter-data.js`：三个章节的章首。
- `vn-controls.js`：自动播放、已读快进、全局已读记录、章首快照与偏好；`sound.js`：本地占位声音；`vn-ui.css`：新增控件与黑屏落版。
- 自动播放等待全文与正文末尾；遇选项、交互、落版停止。快进只处理进入时已读的连续段落，遇未读立即停止；仍经原引擎 `next()` 检查事件，不自动做选项、移动或调查。
- 存读档、菜单、章节重开、隐藏界面、切到后台均取消播放计时器；旧回调不能推进新进度。
- 回顾保留当前周目已读言语；已读快进记录跨章重开保留。章节重开恢复捕获的章首状态，不把奖励加到当前进度上。旧档没有捕获过的章首会标明尚无记录，上庭始终可重新开始。
- 自动档原键不变；原 1–3 手动槽保留，扩展至 12，分三页。所有进度仍是 v2 原字段。
- 全部路线数值在“随身”公开可查，设置内“制作面板”另列实际用途。普通游玩只读；原 `?debug=1` 可编辑，默认不出现编辑入口。
