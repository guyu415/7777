# Mist ripple reference

The EUNOIA opening-screen ripple implementation is substantially modified and
adapted for React from the water-height-field and WebGL refraction approach in
Mist by clunaadke:

https://github.com/eveninwinter/mist

Only the ripple-rendering approach is used. Mist's artwork, fonts, copy,
fog-wiping interaction, and iOS wrapper are not included.

The complete upstream noncommercial license is retained in `LICENSE` beside
this notice.
