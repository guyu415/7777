# fortune-stall inspiration notice

Eunoia's formal divination room is adapted from the interaction and integrity ideas in
wave2234/fortune-stall: server-side casting, an immutable stamped face, a persistent
divination ledger, Xiao Liu Ren dice, Liu Yao coin casting, and Tarot spreads.

The Eunoia implementation is rewritten for Cloudflare Workers + KV and its existing
React interface rather than embedding fortune-stall's FastAPI/SQLite application.
